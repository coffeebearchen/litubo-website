# 响应式验收规范

> 本文件规定所有公开前台页面和 LITUBO Admin 页面的响应式验收标准。不得把手机端留到后期补做。每个里程碑提交时必须包含这些验收结果。

---

## 一、公开前台验收断点

| 断点 | 说明 | 是否强制验收 |
|------|------|------------|
| 1440px | 宽屏桌面（主设计基线） | ✅ 强制 |
| 1280px | 标准桌面 | ✅ 强制 |
| 390px | iPhone 14 / 常见安卓 | ✅ 强制 |
| 375px | iPhone SE / 最小目标 | ✅ 强制 |
| 320px | 极小手机 | 非强制，但不得崩溃 |
| 768px | 平板 | 非强制，但不得有重大视觉问题 |

**所有断点均不允许出现横向滚动条（`overflow-x`）。**

---

## 二、公开前台各模块验收规则

### 2.1 全站通用

| 项目 | 要求 |
|------|------|
| `<html>` lang 属性 | 必须与当前语言一致（`en` / `es` / `pt`） |
| canonical | 英文页面正确；ES/PT 无 canonical |
| hreflang | 英文页面有 `en` 和 `x-default`；ES/PT 无 |
| robots | noindex,follow 页面不得有 canonical；indexed 页面必须有 |
| H1 | 每页唯一；不得为空 |
| 图片 alt 文字 | 所有产品图片必须有 alt；装饰性图片 `alt=""` |
| 焦点可见性 | Tab 键焦点环不被隐藏（`:focus-visible` 可见） |

### 2.2 Header / 导航

| 断点 | 验收项 |
|------|--------|
| ≥1024px | 桌面 Mega Menu 显示正常，五个导航项全部可见 |
| <1024px | 汉堡菜单显示，Mega Menu 不出现；Accordion 折叠展开正常 |
| 375px | 汉堡菜单可点击；所有一级项目可见；无水平溢出 |

### 2.3 产品详情页（新版，9A-2 开始适用）

| 断点 | 验收项 |
|------|--------|
| 1440px | ProductIdBar 深绿识别条显示；PageNav 横排导航；各 section 布局正常；Spec 表格两列显示 |
| 1280px | 布局同 1440px；文字不被截断 |
| 390px | ProductIdBar 可读；PageNav 折叠或单行滚动；各 section 堆叠显示 |
| 375px | 无水平溢出；所有文字可读；图片 max-width:100% |

### 2.4 Spec 表格（技术参数）

| 断点 | 验收项 |
|------|--------|
| ≥768px | 表格正常宽度显示 |
| <768px | 表格父容器 `overflow-x: auto`；手指可横滑；不破容器 |
| 验证方法 | 检查 `table` 外层是否有 `overflow-x: auto` 容器 |

### 2.5 FAQ 折叠

| 项目 | 要求 |
|------|------|
| 展开/收起 | 点击触发；不使用 hover |
| 键盘 | Enter / Space 可触发 |
| 手机 375px | 按钮可点击（最小 44px 可点击区域） |

### 2.6 下载区（PDF / 资料）

| 项目 | 要求 |
|------|------|
| 文件链接 | 直接下载；无登录门槛；无 gate |
| 手机端 | 文件名可读；不被截断 |
| 无下载资料时 | 整个下载区不渲染（不显示空列表）|

### 2.7 MobileConversionBar

| 断点 | 验收项 |
|------|--------|
| <768px | 固定底部显示；不遮挡下方 20% 以上内容 |
| ≥768px | 不显示（或隐藏）|
| 375px | 按钮可点击（最小 44px 高度）；文字不被截断 |

### 2.8 图片

| 项目 | 要求 |
|------|------|
| 所有图片 | `max-width: 100%`；不超出父容器 |
| 产品主图（Hero） | 宽屏不变形；手机端正常缩放 |
| alt 属性 | 产品图片必须有描述性 alt；不使用文件名 |

## 三、LITUBO Admin 验收断点

Admin 界面优先桌面端使用，但手机端不得完全不可用。

| 断点 | 要求 |
|------|------|
| ≥1024px | 主要使用场景；侧边栏展开；表单正常显示 |
| 768px | 侧边栏可访问；表单可用 |
| 375px | 基本可用（输入字段可操作，无水平溢出）；不要求完美布局 |

### 3.1 Admin 各页面最小验收项

| 页面 | 桌面（1440px） | 手机（375px） |
|------|--------------|-------------|
| `/admin/login` | 居中卡片；表单可用 | 表单全宽；按钮可点击 |
| `/admin/products`（列表） | 表格完整显示 | 无水平溢出；可滚动查看行 |
| `/admin/products/new` | 表单两栏布局 | 表单单栏；所有字段可输入 |
| `/admin/products/[id]` | 左列编辑 + 右侧面板 | 单栏堆叠；PublishPanel 可操作 |

### 3.2 Admin 表单验收

| 项目 | 要求 |
|------|------|
| 所有 input | 375px 宽度不被截断 |
| 下拉 select | 可展开，选项可选 |
| textarea | 可输入，resize 正常 |
| 错误提示 | 显示在字段下方或顶部 banner，手机端不遮挡输入框 |
| 保存按钮 | 可点击；loading 状态有视觉反馈 |

## 四、验收方法与工具

| 方法 | 说明 |
|------|------|
| 浏览器 DevTools | 使用响应式模式或设备模拟器调整断点 |
| 截图提交 | 重要断点验收结果须截图并写入报告 |
| 源码检查 | `<title>`、`<meta>`、canonical、hreflang 通过"查看源代码"确认 |
| overflow 检查 | 在 DevTools 控制台执行：`document.querySelectorAll('*').forEach(el => { if(el.scrollWidth > el.clientWidth) console.log(el) })` |

## 五、验收时机

| 场景 | 必须验收 |
|------|---------|
| 每个子 Milestone 完成时 | 1440px + 375px（最低要求） |
| 新增或修改产品详情页组件 | 1440px + 1280px + 390px + 375px |
| 修改 Header / Footer / MobileConversionBar | 1440px + 375px |
| 修改 Admin 任何页面 | 1440px + 375px |
| 修改 CSS tokens / base.css | 1440px + 375px（全站抽查） |

---

## 六、禁止事项

- 禁止把手机端验收留到"下个 Milestone 再补"
- 禁止以"Admin 只有内部使用，不用管手机"为由跳过 375px 验收
- 禁止使用 `overflow-x: hidden` 掩盖横向溢出（根本原因必须修复）
- 禁止在手机端为了省事直接 `display: none` 整个模块（须有可访问的降级方案）
