# 安装说明：直接解压到现有 LITUBO 仓库

本压缩包的内部路径已经按现有仓库设计。请将 ZIP 解压到：

```text
D:\LITUBO-website\
```

解压后只会新增：

```text
docs\product-cms\CMS-AI-CONSTRUCTION-PACK-V1\
docs\design-reference\CMS-AI-VISUAL-MASTER-V1\
```

不会写入或覆盖：

```text
CLAUDE.md
docs\project\
docs\product-cms\ 中已有文件
docs\design-reference\ 中已有官网母版
private-product-source\
```

安装后先让 Claude 执行 S0 只读核验；在用户确认差异报告前，Claude 不得移动、合并、改写或删除任何既有项目文件。
