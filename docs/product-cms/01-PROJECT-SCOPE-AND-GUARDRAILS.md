# 01｜分层产品页面原则

## 五层结构

1. **全站层**：Header、Footer、色彩、字体、移动端转化条，完全统一；
2. **页面骨架层**：产品识别条、Hero、页内导航、底部 CTA，基本固定；
3. **类别预设层**：按产品类别建议一组模块和默认顺序；
4. **内容模块层**：产品可启用、隐藏及在允许范围内排序；
5. **真实资料层**：图片、文字、参数、PDF、FAQ、SEO，逐产品维护。

## 受控灵活

内容人员可填写内容、上传资料、启用模块、在中段调整顺序、选择规定的图文变体。只有管理员/开发人员可新增一种模块类型或改变全站视觉系统。

## 发布状态

`draft` → `review` → `published` → `archived`。删除采用 archived，不直接物理删除。产品若缺少名称、类别、slug、Hero、摘要或有效发布状态，不得公开。
