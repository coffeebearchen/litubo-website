# 02｜详情页设计与模块规则

## 固定骨架

白色双行 Header → 深绿产品识别条 → 页内锚点导航 → Hero → 中段可组合模块 → 底部 CTA → Footer。手机端保留折叠菜单与 WhatsApp / Technical Matching 固定转化条（在 technical-matching 页面隐藏）。

## 模块库

| 模块 | 内容 | 规则 |
|---|---|---|
| Quick Facts | 3–6 条简短事实 | Hero 后，建议启用 |
| Overview | 图片、标题、正文 | 建议启用 |
| Image Text | 图文说明 | 左图右文/右图左文/宽图置顶 |
| Benefits | 2–6 项优势 | 只填真实、可证实内容 |
| Applications | 行业、物料、场景 | 可选 |
| Detection Targets | 可检测目标 | 仅真实技术范围 |
| Working Principle | 2–6 步原理 | 可选 |
| Configuration Options | 配置、型号差异 | 可选 |
| Line Integration | 产线衔接 | 可选 |
| Specification Groups | 参数分组、参数行 | 建议启用 |
| Gallery / Video / Downloads | 媒体资料 | 无资料即隐藏 |
| Case Studies | 已批准真实案例 | 无案例即隐藏 |
| Related Products / FAQ | 关联产品、真实 FAQ | 可选 |

## 排序限制

Hero、Quick Facts、底部 CTA、Footer 固定；Overview 至 Configuration 可调整；Specifications、Downloads、FAQ 原则上处于后半段。单页建议最多 10–14 个公开模块。

## 语义规则

产品名称是唯一 H1；模块标题是 H2；模块小标题及规格组是 H3；正文使用 Paragraph；图片说明和测试条件使用 Caption/Note。后台不得要求内容人员选择 H 标签。
