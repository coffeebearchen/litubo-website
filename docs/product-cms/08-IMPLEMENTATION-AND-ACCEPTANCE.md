# 08｜实施、验收与分模块计划

## 模块 0：只读差异核对

读取现有档案、Git、Docker、Directus schema 与前端产品页，给出计划。无修改。

## 模块 1：人工产品 CMS 基础

实现数据模型、权限、人工表单、页面预设、模块库、媒体角色、规格组与 FAQ。实施前导出 schema 快照与数据库备份；不得写假产品。

## 模块 2：模块化详情页

实现 ViewModel 适配层、前端模块注册表、桌面/375px 页面、语义 SEO、空状态与错误状态。保留既有全站组件。

## 模块 3：LT-180C 真实样板

仅用用户确认的资料录入 Draft，核对页面源代码、桌面、手机、下载与询盘入口。用户确认后才 Published。

## 模块 4：AI 导入助手

实现资料上传、来源解析、Provider Adapter、结构化 Draft、审计、审核 UI。先用 mock provider 测试，不放真实 Key；用户另行授权后才连接 API。

## 每个模块验收

- typecheck、lint、build 通过；
- 浏览器桌面 1440px、手机 375px，无横向溢出；
- SEO 语义正确；
- 无假数据写入 Directus；
- 中文报告、截图、本地 commit；
- 未获明确授权不得 push/部署。
