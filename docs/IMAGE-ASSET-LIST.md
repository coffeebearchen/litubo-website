## Naming rules

- All filenames: lowercase English letters, digits, hyphens only — no spaces, underscores, or special characters.
- Slugs in filenames must match the route slug exactly (e.g. `xr-demo-series` → `xr-demo-series-hero.jpg`).
- Supply original/high-res sources separately; do not commit files larger than 2 MB to the repository.
- When an image is not yet available, the page falls back to the CSS gradient placeholder automatically — no broken-image icons.
