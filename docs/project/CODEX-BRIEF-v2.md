【A. 设计与体验方向】

让网站"有生机、有结构感、有设计感"。

- 明确区分：不需要新素材就能做 vs 需要业主提供照片或数据

不要写"多用圆角""增加留白"这类空话。

【B. 当前站点的具体错误与缺陷】

请实际阅读 pages/ 与 components/ 代码，点名指出问题：
- 结构问题（信息层级、导航、路径断裂）
- 视觉问题（对齐、间距、颜色误用、图文关系）
- 体验问题（移动端、加载、可读性）
- 内容问题（重复、空洞、缺说服力）

每条给出「位置 + 问题 + 修法」。

【C. 智能与获客能力 —— 本次重点】

决策者已点名要的：表单、AI 客服引导、访客通知（页面/时间/国家）、
企业微信通知。

请在此基础上，给出**完整的智能与获客能力清单**。先回答：

  Q1. 一个工业 B 端设备站，除了上述四项，还应该具备哪些
      智能能力与获客功能？请尽量穷举，并按「直接带来询盘 /
      提升转化率 / 提升信任 / 内部效率」四类归组。

  Q2. 结合我们这个站已有的能力（访客追踪、AI 挂件、表单、
      企业微信），哪些功能可以**低成本快速落地**？
      哪些需要较大投入？

  Q3. 这些能力之间应该如何**串成一条线**？
      例如：客户从 Google 进来 → 看产品 → AI 主动引导 →
      留下线索 → 通知销售 → 销售跟进。
      请画出这条链路，并指出每一环目前缺什么。

**对每一项能力，请给出：**
  - 思路（它解决什么问题）
  - 实施方案（技术路径、需要哪些数据、需要改哪些页面）
  - 依赖（是否需要业主提供素材/账号/预算）
  - 预估工作量（小时）
  - 优先级（P0 上线前必做 / P1 首月 / P2 以后）
