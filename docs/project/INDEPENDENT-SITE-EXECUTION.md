## 本轮首包：真实缺陷与迁移底座

Framework：Governing Charter V1.1，相关 E（架构）、G（数据/生命周期）、H–I（AI/安全）及渐进兼容约定；现有后台视觉母版不变，本包不重排 Admin 全局导航。

触及 RSG-06（新关联不能引用已归档文件；使用中的主图不能被归档）、RSG-07（检查失败拒绝）、RSG-08（测试和生产分开）、RSG-09（不自动升级授权）。所需证据：关联缺失/归档/权限失败负向测试，首页/分类/产品/旧博客直接媒体引用保护，当前代码测试结果。公开媒体输出规则保持原有 fail-closed 合同。

迁移底座触及 RSG-01/03/04：只生成草稿候选，不自动发布，不将来源中的文字当作执行指令，不运行网页脚本。真实数据只能保存在私有工作目录。现有 collection 和字段优先复用，有必要才做隔离 schema 补充。
