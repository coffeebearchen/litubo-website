# V2验收与回退清单

这是施工验收要求，不是已执行的测试报告。设计阶段仅核对源码与静态UI；运行结果由DSH填写。

| 范围 | 正向验收 | 反向/回退验收 |
|---|---|---|
| 字段 | 新建/编辑称重三字段保存后重读一致，空编码可首次设定 | 已设编码不改；false/null保持；非draft原保护有效 |
| 产品入口 | 七日常页和三个独有工具可操作、可返回 | 四个旧路径跳转；旧文件保留；恢复导航可回旧入口 |
| Blog | 新编辑器改posts，列表/详情同封面同正文 | 不生成CC-only错误Blog链接；Case Study真实路径保持 |
| Hero默认 | 13页空配置/空值/未发布/CMS故障有批准默认 | 私有/归档图片不输出UUID或Directus原地址 |
| Hero预览 | 本地预览与公开呈现组件相同 | Preview零数据库写；刷新丢本地修改提示准确 |
| Hero发布 | 明确Publish后该行字段一次变更且公开页采用 | 受影响字段先备份；撤回回默认不谎报保留旧覆盖 |
| 老接口 | home-content原GET/PATCH含义不变 | 老调用不被偷偷写到草稿别行；允许列表不任意扩展 |
| 分类/媒体 | 分类写原collection；主图角色和排序一致 | 引用保护/软归档不绕过；共享媒体title提醒准确 |
| cover_fit | contain/cover控制已确认封面，null兼容旧清单 | 非法值拒绝；回退保留新列，不DROP或整表恢复 |
| 询盘AI | 合成记录Generate→人工确认→现有AI列写入 | Generate不写；Discard不清原文/旧结果；不自动回复/分配 |
| AI过期/证据 | 未审/已确认区分，缺证据红色加文字 | 原文变更/其他管理员提案不可确认；无假置信度 |
| 权限 | 原Admin认证/现有角色继续有效 | 未授权不能调用新写API；前台不能读私有草稿/AI结果 |
| 视觉 | 1440与390对照UI-01…05 | 不是用设计PNG冒充实现；手机无整页横溢/固定控件遮挡 |
| 回退 | 每批记录恢复用时≤5min | 超过拆批；不覆盖其他人变更；禁止整库恢复 |

每一批只跑相关关键链路与必要typecheck/build；新失败才重复。真实环境缺权限/模型未配/业务未知资料分别标明，不能以mock成功宣称生产就绪。

DSH回报模板：任务ID｜状态（待做/进行/完成/待资料）｜提交｜实际变更｜验证与截图｜回退步骤和实测时长｜未完成/需业主确认。最终“可审查”与“已部署/生产可用”分开标记。
