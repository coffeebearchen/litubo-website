# 02 — Scope and acceptance

## Phase 1 — publishable lead-generation core

Goal: a visually confirmed, responsive English-first website with a minimal content backend that lets a buyer understand LITUBO, explore systems/applications, and start a qualified conversation.

| Included | Deferred |
| --- | --- |
| Global shell: Header, mega menu, mobile navigation, Footer, cookie/privacy links | CMS/editor accounts and publishing workflow |
| Design tokens and reusable button, card, form, filter, pagination, CTA components | HubSpot live write, email notification and anti-spam production keys |
| EN + ES + PT technical framework; EN content first, ES/PT fields/key coverage | Public ES/PT until translations are complete |
| Home, Products overview/category/detail, Applications overview/detail | Insight/case-study library and editorial detail pages |
| Contact, Technical Matching, Find a Distributor visual/form flows | Authenticated download centre and gated assets |
| SEO defaults, sitemap generation, robots, 404, privacy/terms | Advanced site search and resource analytics |
| Functional form submission to approved mailbox/records; honest success flow | Live deployment, DNS change, Wix migration until separately approved |
| Minimal CMS: manual products, media/Hero, YouTube/server-video links, Resources/Blog, form records | Excel bulk import, HubSpot write, newsletter subscription |
| AI drafts for Blog and internal customer communication, always human-reviewed | Public AI chat, automated publication/email/messages |

### Phase 1 acceptance gate

1. Every included page is reachable from the approved navigation and has a working EN/ES route.
2. Desktop and mobile layout match the approved visual hierarchy; no horizontal overflow at 320/375/768/1024/1440px.
3. Menu is mouse- and keyboard-operable; mobile menus use accordions; visible focus and basic accessibility pass.
4. Every published form validates, reaches its approved mailbox/record store, and presents an honest success state.
5. Lint, typecheck and production build pass; core routes have title, description, canonical and social metadata.
6. Content uses only supplied/approved information. Design-demo names, performance claims, events, careers, email addresses and response commitments never reach production.

## Phase 2 — content, support and operations

- Excel import with preview/validation, advanced content workflow and publishing roles.
- Resources filters/search and expanded editorial detail templates.
- Support overview; FAQ, manuals, parts, service/training and product-test request pages.
- Company: About, Quality & Manufacturing, Global Service, Events, Partner and Careers.
- Explicit HubSpot API integration, newsletter subscription, advanced anti-spam and consent operations.
- Performance/accessibility audit, analytics/consent configuration, staging review, production deployment and Wix cutover approval.

## Not in either scope unless separately approved

Public e-commerce, customer login, online payment, distributor portal, quotation engine, customer claim portal, artificial case data, or automated customer-email campaigns.
