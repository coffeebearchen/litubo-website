# 待补素材：怎么办

**一句话：不用一次给完，也不用现在给。上线不等素材。**

---

## 一、只需要做一件事

打开同目录的 **`待补素材清单.csv`**（Excel 可直接打开），里面只有 **13 行**：

- 5 行：各产品分类的代表图
- 8 行：缺图的产品

## 二、怎么给（三种方式，选最省事的）

| 方式 | 做法 | 适合 |
|---|---|---|
| **A. 按文件名丢**（推荐） | 把照片按清单里的「建议文件名」命名，放进 `产品/` 和 `分类/` 两个子文件夹 | 有原图库 |
| **B. 随便命名** | 把照片丢进文件夹，我按内容人工对应 | 图不多 |
| **C. 让拍摄方直接给** | 把这份 CSV 转发给拍产品照的人 | 要新拍 |

**文件名可以不完全一致**，清单里的名字只是建议。只要照片能看出是哪个型号，我都能对应。

## 三、照片要求（不高）

| 项 | 要求 |
|---|---|
| 格式 | JPG / PNG 都行 |
| 尺寸 | 长边 ≥ 1200px 即可 |
| 背景 | 白底最好，浅灰也行 |
| 角度 | 产品正 45° 或正侧面 |
| 不用修图 | 我这边统一处理 |

## 四、没有图会怎样？

**能上线，只是不好看。**

现在缺图的位置显示的是**品牌化占位图**（深绿渐变 + 暖橙光晕 + 图标），不是破图、不是空白。

所以：

- 可以带着占位图上线
- 上线后任何时候补图，前台立刻生效（不用改代码）
- 补图不影响 SEO、不影响结构

## 五、这 13 张图，优先级怎么排？

如果只能先给一部分，按这个顺序：

| 优先 | 给哪个 | 理由 |
|---|---|---|
| **1** | 5 张分类图 | 首页五张卡是全站第一屏，最显眼 |
| **2** | XR-50C、XR-100C | 便携 X 光，客户常问 |
| **3** | 其余 6 个 | 工业/特殊型号，流量小 |

## 六、和上线的关系

```
现在 ──→ 部署预览站（不需要任何图）
         ↓
      客户/同事在预览站审阅
         ↓
      素材慢慢补（每次补几张都行）
         ↓
      素材齐了 + 关 Wix → 切主域名
```

**不要为了等图推迟上线。**

---

## 附：如果连这 13 张都暂时找不到

那就先上线，把这些位置当"暂无实拍图"处理。客户看到的是设计过的占位图，不会觉得是坏网站。

**唯一不能做的**：用别的产品图顶替（会造成客户错配）。这一条不能让步。
