# Admin CMS / AI visual references — Draft input only

## Status

These eight desktop images are external layout and interaction references. They must not be treated as approved visual masters or as code specifications.

## What may be learned from them

- Three-column admin workspace and information hierarchy.
- Product catalogue, technical category views, specifications, linked media/resources, controlled page modules, relations, SEO, and source/evidence review.
- Clear review/publish blockers, readiness, and audit presentation.
- Product records link to media by UUID/reference rather than owning copies of files.

## What is not adopted automatically

- The shown models, parameters, counts, dates, images, and people are fictional demonstration data.
- English is the confirmed primary language for the admin interface. Chinese may be used in internal documentation, training notes, or help content, but is not the UI baseline.
- No page may be implemented directly from these pictures.
- Media folder rules must be validated by the server. Client-side dropdown filtering is never a security boundary.
- AI scope remains one selected Product Draft plus its frozen Source Snapshot; it must never scan all product folders or mixed model data.

## Current gaps in this reference set

- It contains desktop references only; it is not a 375px mobile specification.
- It does not contain the final single-product AI source snapshot, run, suggestion comparison, field lock, accept/reject, and new-version flow.
