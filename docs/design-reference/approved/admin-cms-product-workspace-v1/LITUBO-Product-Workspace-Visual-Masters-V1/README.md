## Reading rule for Claude

Before coding a Workspace screen, Claude must open the exact named visual master at full size, then read the relevant governing documents, child blueprint, route/data contract and acceptance requirements. The image controls layout and visible interaction intent; it does not authorize invented data, technical facts, customer access or publication behaviour.

## Desktop and mobile status

Every supplied source image is 1672 × 941 pixels and is classified as a D1440 desktop reference for acceptance. No M375 mobile visual master is included in this pack. Each code task must still verify 1440px and 375px; any mobile visual decision not established by a master must be reported for approval.
