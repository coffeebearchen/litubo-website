# LITUBO new website — start here

This folder is the handoff package for the new LITUBO website. It contains no business-page source code and must be placed in the root of the future Claude Code project.

## Reading order for Claude Code

1. `CLAUDE.md`
2. `docs/project/00-current-status.md`
3. `docs/project/01-technical-decision.md` through `09-claude-first-read-only-instruction.md`
4. `docs/design-reference/README.md`
5. The relevant approved design image(s) for the module being implemented

## Non-negotiable rule

Files under `docs/design-reference/approved/` are visual reference material only. Do not use them as website runtime assets, copy any placeholder business claims from them, or alter the approved menu/page hierarchy merely for coding convenience.

## Folder roles

- `docs/project/`: binding implementation rules, models, routes and acceptance criteria.
- `docs/design-reference/`: approved design source and its page/module mapping.
- `docs/content/inbox/`: user-provided Word, PDF, Excel and source notes awaiting structured review. Do not use an item publicly until it is verified.
- `docs/content/LITUBO_content_templates.xlsx`: three empty working templates: Product Master, Content Status and Asset Manifest.
- `assets/source/`: real supplied product photos, certificates, videos and original marketing masters; do not expose this folder directly on the website.
- `public/` and `assets/` (created after Module 0): optimized, approved runtime web assets only.
